# Image Processor — редактор изображений

## 1. Описание проекта

Image Processor — настольное приложение на Python для графической обработки изображений. Программа позволяет загружать изображения (включая поддержку Drag & Drop), интерактивно обрезать выделенные области, переводить изображения в оттенки серого, изменять разрешение, вести историю операций и сохранять результаты с автоматическим логированием событий.

---

## 2. Используемые технологии

* **Python 3.10+** — основной язык программирования.
* **PyQt5** — создание графического интерфейса пользователя (GUI).
* **Pillow (PIL)** — библиотека обработка изображений.
* **Unittest** — автоматическое модульное тестирование.
* **JSON** — хранение истории действий и конфигураций.
* **Logging** — журналирование процессов и ошибок.

---

## 3. Возможности программы

* Открытие и просмотр изображений различных форматов (PNG, JPG, JPEG, BMP).
* Поддержка загрузки файлов способом Drag & Drop (перетаскивание в окно).
* Интерактивное выделение прямоугольной области мыши для обрезки (Crop).
* Быстрая конвертация изображения в оттенки серого (Grayscale / Ч/Б).
* Пропорциональное или свободное изменение ширины и высоты изображения (Resize).
* Многошаговая отмена действий (Undo) с восстановлением прошлых состояний.
* Просмотр метаданных и параметров текущего изображения (размер, формат, режим).
* Автоматическое сохранение обработанных файлов в отдельную папку `output/`.
* Фиксация истории всех операций пользователя в файле `configs/history.json`.
* Ведение подробных системных логов в `logs/app.log`.

---

## 4. Структура проекта

* `project_3.py` — запуск приложения и графический интерфейс (PyQt5).
* `test_image_processor.py` — модуль автотестов (Unittest).
* `configs/` — служебные настройки и история действий (`history.json`).
* `logs/` — журнал событий и ошибок приложения (`app.log`).
* `output/` — директория для сохраненных результатов обработки.
* `docs/` — проектная документация и UML-диаграммы.

---

## 5. Установка и запуск

1. Установите Python версии 3.10 или выше.

2. Установите необходимые зависимости:
   ```cmd
   python -m pip install PyQt5 Pillow
   ```

3. Перейдите в папку проекта и запустите приложение project_3.py

---

## 6. Запуск тестов

Из корневой папки проекта выполните команду:

```cmd
python -m unittest test_image_processor.py
```

Тесты проверяют корректность функций обрезки, перевода в оттенки серого, изменения размеров, обработку некорректных путей и выявление ошибок формата.

---

## 7. Обработка ошибок

Программа проверяет корректность загружаемых файлов, допустимость геометрических размеров при кропе и наличие путей сохранения. Все возникающие сбои не приводят к аварийному завершению приложения: они логируются в журнал `logs/app.log`, а пользователю выводится информативное сообщение через интерфейс.
